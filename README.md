# Alfred Workflows Collection

收集整理常用的 Alfred Workflows。

## Stacks2 Tasks

Stacks2 Tasks v1.0.0 是一个用于快速向 Stacks 2 的 Project 或 Stack 录入任务的 Alfred workflow。

- `s reload`：选择并扫描 Stacks 项目目录
- `s`：选择 Project 或 Stack
- `任务标题 | 任务说明`：快速创建任务
- 无需 Stacks 应用保持前台运行
- 安装包包含 Apple Silicon 可执行文件及 C++ 运行库

下载：[Stacks2.alfredworkflow](Stacks2.alfredworkflow)

源码与完整说明：[Stacks_Tools/README.md](Stacks_Tools/README.md)

标签：`Stacks2`

## Yabai Control

Yabai Control v1.1.0 是一个用于快速管理 yabai 的 Alfred workflow。

- 启动、重启、停止及检查 yabai 服务
- 查看 yabai 版本
- 列出当前显示器和空间中的窗口进程
- 忽略或解除忽略当前应用，并将规则持久化到 `~/.yabairc`
- 同时兼容官方 yabai 与支持 macOS 27 的 yabai 分支

下载：[Yabai Control.alfredworkflow](Yabai%20Control.alfredworkflow)

标签：`Yabai`
