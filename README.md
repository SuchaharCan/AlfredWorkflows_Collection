# Alfred Workflows Collection

收集整理常用的 Alfred Workflows。

## Yabai Control

Yabai Control v1.1.0 是一个用于快速管理 yabai 的 Alfred workflow。

- 启动、重启、停止及检查 yabai 服务
- 查看 yabai 版本
- 列出当前显示器和空间中的窗口进程
- 忽略或解除忽略当前应用，并将规则持久化到 `~/.yabairc`
- 同时兼容官方 yabai 与支持 macOS 27 的 yabai 分支
